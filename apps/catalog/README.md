# Visual catalog

The Storybook that shows every component in every state. It arrives in phase F6
together with the first component, because a catalog with nothing in it proves
nothing.

It is not a nice-to-have. Several rules in the foundations can only be checked
here: every state of a component on one page, light and dark side by side (not
toggled), LTR next to RTL, both densities, and a resizable container. Without
the resizable container half the responsive checklist cannot be verified at all.

Deploying it publicly is one of the conditions for releasing the rewrite.
