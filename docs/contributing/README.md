# Contributing docs

How to _work on_ the library. Repository-level workflow lives in
[../../CONTRIBUTING.md](../../CONTRIBUTING.md); this folder holds the detailed
recipes.

The important one is `new-component.md`: the exact file layout of a component,
the steps to build one, and the twelve-checkbox entry gate as a checklist you
can actually run. It is what makes a contributor — or an AI agent — productive
without reading all ten foundations first.
