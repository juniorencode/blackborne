# Foundations

Permanent rules. These are written _before_ the code they govern, and changed
_before_ writing code that contradicts them — never afterwards to justify it.

The documents and their order are listed in [../README.md](../README.md). They
are being written in phase F4; two of them (02 · API conventions and 08 ·
Layers and focus) wait for the React Aria spike, because that spike is what
decides their content.
