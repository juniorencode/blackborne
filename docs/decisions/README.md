# Decisions

One file per decision, named `NNNN-short-title.md`, dated, append-only.

A decision is recorded here when it closes a question that would otherwise be
re-argued: the headless base, distributing compiled CSS, keeping validation out
of the library, shipping RTL from day one.

Each file states: the date, the context, the decision, and the consequence that
follows from it. A decision is superseded by a later one, never edited in place
— the point of the folder is that you can see what was believed when.
